# Stationeers IDE

> **Unofficial fan-made tool.** Not affiliated with, endorsed by or supported
> by RocketWerkz. Stationeers is a game by RocketWerkz, who own its name.

Write, debug and simulate Stationeers IC10 scripts in your browser: build a
model of your devices and their data, pipe and power networks, run the chips'
code at any speed, step through it, and push values to extremes to find the
edge cases before your base does.

**Use it:** https://stationeers-ide.github.io/

**Run it offline:** download the zip for Windows or Linux from
[Releases](https://github.com/stationeers-ide/stationeers-ide.github.io/releases),
unzip it and run `stationeers-ide`; its `README.txt` explains the rest.

Everything runs in your browser; nothing is sent anywhere. Projects autosave in
the browser, per address, so the website and the offline version keep separate
projects. Use Save / Open to move one between them.

## About this repository

It holds only the built web app, published from each release; please report
problems and ask for changes in its
[issues](https://github.com/stationeers-ide/stationeers-ide.github.io/issues).
